# 内置依赖 `@xbb/core`

本目录是 `@xbb/core` 的**只读副本**，随本仓一同发布。目的是让任何人 `git clone` 之后就能直接构建，不需要访问私有仓，也不需要配置跨仓 token。

- **唯一真源**：私有仓 `sji-xiaobenben/xbb-core` 的 `packages/core/`（你访问不到，这是有意的：本目录就是给公开仓用的完整副本）
- **不要直接修改这里的文件**：下次同步会覆盖
- **同步**：`bun run core:sync` —— 仅供维护者使用，要求同级目录存在 `../core`。**外部贡献者不需要执行**，本目录已随仓提供完整副本
- **校验是否漂移**：`bun run core:check`（同理，维护者用）

副本对应的上游提交号记录在 `VENDORED.md`。
