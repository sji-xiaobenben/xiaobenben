# 本地管理页的界面规范（`src/web/admin.ts`）

这份文档只讲一件事：**改 `ADMIN_HTML` 那个模板字面量时，什么能改、什么不能改、凭什么**。
它不重复 `server/docs/DESIGN.md` §27（七档色阶与纪律），只记录本页在 §27 之下做的取舍。

---

## 1. 本页的定位与豁免边界

`xbb serve` 打开的是一个**零依赖单文件页**：HTML / CSS / JS 全部内嵌在 `admin.ts` 的
一个模板字符串里，不加载任何外部资源，不经过构建，产物就是那段字符串本身。

因此 §27.8「exe 壳内 UI 走 Vue + antd」在这一页**不适用**——引 antd 意味着引入构建链和
几百 KB 运行时，与「零依赖 + 单文件」直接冲突。本页适用 §27.8 里的**展示型豁免**：
照用七档色阶与本子隐喻，但不引组件库。

豁免的代价是自己维护组件规范，就是下面这些。

## 2. Token 映射（唯一真源仍是 DESIGN.md §27）

| CSS 变量 | 日间 | 夜间（`prefers-color-scheme:dark`） | 用途 |
|---|---|---|---|
| `--bg` | `#FFFFFF` | `#111111` | 页面底 |
| `--card` | `#FFFFFF` | `#222222` | 卡片面 |
| `--chip` | `#EEEEFF` | `#2A2A38` | 选中底 / 标签底 / code 底 |
| `--acc` | `#2255BB` | `#2255BB` | 主行动色（全站唯一） |

| `--tx` | `#222222` | `#F2F2F2` | 正文 |

| `--tx3` | `#222` @62% | `#F2F2F2` @58% | 三级文字（≥4.5:1） |

| `--dng` / `--wrn` | `#A32D2D` / `#8A5A00` | `#E89292` / `#D9A85C` | 语义色（暗底必须提亮，否则不可读） |
| `--kd` / `--kc` | `#2255BB` / `#A32D2D` | `#5B8DEF` / `#DE6B6B` | **色条专用**（色块比文字需要更高饱和） |

分级原则：**卡片靠阴影分层，不靠底色差**（§27.2）。日间是白底白卡 + `0 5px 30px rgba(0,0,0,.05)`，
夜里靠 `#111` / `#222` 的色差。卡片上那条 7% 的描边只是低对比度屏幕上的形态兜底，不承担分层职责。

## 3. 三条硬纪律

### 3.1 唯一行动色

一屏只允许一个主按钮（`.pri`）。当前是搜索框旁的「搜索」；云端区的「切换到云端」在独立区块内，
不与搜索竞争。其余按钮一律中性描边，危险动作用 `.dgr`（红字描边，非实心红底）。

### 3.2 默认态不给颜色

左强调条（3px）**只标「非默认分类」**：

| kind | 色条 | 理由 |
|---|---|---|
| `memory` | 无 | 默认态。给它上色等于让 80% 的卡片都在喊 |
| `directive` | `--kd` | 有时效，需要被看见 |
| `habit` | `--r3` | 长期影响行为，弱提示 |
| `constraint` | `--kc` | 限制 AI 行为，安全相关 |

徽章同理：`#9999DD`（档3）**只做填充，不做白底文字**（2.6:1，§27.6 明文禁止）。
`habit` / `ep-a` 的文字退到 `--tx2`，靠色点与色条区分。

### 3.3 禁内联样式

静态样式一律进 `<style>`，JS 只允许用 `style.display` 控制显隐（那属于状态，不是样式）。
2026-11 改造时清掉了 27 处内联 `cursor` / `color` / `margin`，改成语义类：
`.dim` `.warn` `.dng` `.mt` `.cl` `.static` `.acts.l` `.badge.lock` `.badge.vault`。

## 3.4 提示条只做"说明"，不做"告警"

`.tipbar` 是页面里唯一允许出现的**说明性**横幅（替换掉了一度想用的弹窗）。四种状态同一套骨架：

| 状态 | 左边条 | 图标 | 谁在用 |
|---|---|---|---|
| `tip` | `--acc` | `--link` | 首次到访的温馨提示（可「知道啦」永久收起，存 `localStorage`） |
| `busy` | `--acc` + 脉冲点 | 无 | 后台正在整理会话（纯状态，不用用户做任何事） |
| `off` | `--tx3` | `--tx3` | 用户关掉了自动整理（必须给出「重新开启」的回头路） |
| `warn` | `--wrn` | `--wrn` | 连续两轮失败 —— 才值得提一句 |

两条纪律：

1. **文字色用 `--link` 不用 `--acc`**。`--acc`（`#2255BB`）在夜间底上只有 2.6:1，`--link` 夜间自动提亮到档3。
2. **短的一轮不弹**：`busy` 只在采集已跑超过 2 秒时才出现。增量轮通常 1–2 秒，
   每 5 分钟闪一下又消失比不提示更烦；首次全量入库要十几二十秒，那时才值得说"正在整理"。
3. **不要用 emoji 当图标**。`📖` 在缺 emoji 字体的环境会渲染成豆腐块（headless Chrome 实测），
   一律内联 SVG + `currentColor`。

## 4. 本子隐喻三件（§27.5）

1. **页码凭证号**：每张卡片右上角 `No.XXXX`（UUID 取末 4 位，短数字补零）。完整 id 退到
   `title` 属性——把 36 字符 UUID 铺在 meta 行里是纯噪音，而它又必须能被查到。
2. **左强调条**：见 3.2。
3. **书签角标**：顶栏的方形书签 icon，与 exe 图标同一份几何（`M2 0h14v22l-7-5-7 5z`）。

## 5. 体积预算

**度量对象是产物，不是源文件。** 源码里的注释不进产物（模板外的 `//` 注释在 TS 层，
模板内的会被浏览器收到），所以：

```bash
# 导出真实产物，对比改动前后
bun run tools/check-admin-html.ts --emit /tmp/new.html
wc -c /tmp/old.html /tmp/new.html
```

2026-11 那次改造的结果：产物 49402 → 48761 字节（−1.3%），功能零删减。
新增了夜间模式、顶栏、页码、组件体系，靠三件事抵掉：模板内注释全部搬到 TS 层（−3.3 KB）、
CSS 注释搬出、内联样式收敛成语义类。

## 6. 三道闸（改完必跑）

| 闸 | 挡什么 |
|---|---|
| `bun run tools/check-admin-html.ts` | 模板字面量吃掉反斜杠 / `${}` 非裸标识符 / 内联脚本语法错 / `onclick` 引用了不存在的函数 |
| `bun run tools/admin-ui-check.ts` | 无头浏览器真开一遍，断言云端三态渲染文案（静态分析证明不了"真的跑起来了"） |
| `bun test` | 187 项，含 `serve.test.ts` |

还有一条非强制但强烈建议的自查：**JS 里生成的 class 是否都有对应 CSS**。
改动常犯的错是改了类名忘了改样式，页面不报错、只是"少了一点样子"，肉眼容易漏。
